SO100 Near-Apricot Counterfactual Report

165 query frames: prev rollout 77, curr rollout 88. Candidate threshold: gripper-apricot distance <= 70 px. FM seeds 0/1/2 are averaged per frame before ranking; MLP is deterministic.

Key Takeaways

Primary approach ranking.
按 30-step 内最接近 apricot 的 best progress 和 per-frame mean rank，FM SO100-only 60k/80k 排在前两位，均值约 6.9 px。
MLP behavior.
MLP 在单帧 winner count 上很多，但 overall final progress 为 -0.91 px，说明它常有短暂靠近，最后 30-step 末端又退远。
Cotrain / 5xGrip.
Cotrain close rate 最高，但靠近量没有超过 SO100-only；5xGrip 也没有带来更强的 apricot approach。后续 per-horizon 分析显示 Cotrain 的 early direction 可以更好，但 target-axis progress 不持续。

Follow-up Findings

Cotrain is not uniformly worse.
在 approach_50_70，Cotrain 的前 10 步方向/进展有局部优势，尤其相对 SO100 60k。
Final execution is still weaker.
到 horizon step 30，Cotrain 在 close、near、approach 三个距离段对 SO100-only 的 final progress delta 都是负的。
Representation hypothesis.
Human right-arm action 是 future observed hand pose；SO100 action 是 fixed-camera robot command pose。Rotation/action 语义差异很可能是 cotrain 负迁移来源。

Representation Hypothesis And Next Experiment

当前 SO100 和 human 虽然都进入 actions_cartesian，但语义不同。SO100 使用 fixed-camera robot EE command pose；human ego-view 使用 future observed right-hand pose，并转到 current head frame。动作语义差异客观存在，尤其 rotation frame/axis 定义很可能不一致。

因此我新增了一个 xyz-only cotrain 训练配置：human no-gripper action layout 是 [x, y, z, yaw, pitch, roll]，只保留 human xyz loss，mask human rotation loss；SO100 action loss 仍然全维度正常训练。

如果这个 experiment 保留远距离 direction advantage，同时改善 close/near final progress，就支持“human 数据有语义帮助，但 rotation/action representation mismatch 伤害 SO100 control”的解释。
